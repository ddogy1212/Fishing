# Fishing 🎣

Android용 카카오톡 낚시 버튼 인식 자동 클릭 도구.

- 1.8~2.2초 랜덤 클릭 간격
- 스크린샷의 한글 OCR로 **'낚시'** 버튼만 탐색
- 왼쪽/오른쪽 버튼 위치 자동 추적
- 카카오톡(`com.kakao.talk`)이 활성화된 동안만 동작
- 인식 실패 시 클릭하지 않으며 사용자가 앱에서 시작/중지
- 화면 데이터는 기기 내에서만 처리하고 외부 전송 없음

## APK 받기

1. GitHub 저장소 상단의 **Actions** 탭을 엽니다.
2. **Build Android APK** 워크플로에서 성공한 실행을 선택합니다.
3. 화면 아래 **Artifacts**의 **Fishing-debug-apk**를 눌러 ZIP을 다운로드합니다.
4. ZIP을 풀어 `app-debug.apk`를 설치합니다.

## 사용법

1. Android 11(API 30) 이상 기기에 앱을 설치합니다.
2. 앱에서 **접근성 설정 열기** → **Fishing 도우미**를 활성화합니다.
3. 앱으로 돌아와 **자동 낚시 시작**을 누릅니다.
4. 카카오톡의 낚시게임 채팅방으로 이동합니다.
5. 종료하려면 Fishing 앱으로 돌아와 **중지**를 누릅니다.

참고: 카카오톡/게임의 화면 구성 또는 정책이 변경되면 작동하지 않을 수 있습니다. 자동화 허용 여부는 게임 이용규칙에서 확인하세요. 접근성 권한은 화면 읽기/터치를 위해 필요합니다.

## 빌드

Android Studio로 프로젝트를 열거나 JDK 17과 Gradle 8.9를 이용해 `gradle assembleDebug` 실행. GitHub Actions가 푸시마다 자동 빌드합니다.
